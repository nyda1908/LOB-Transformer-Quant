# Data

This project uses the **FI-2010** benchmark dataset for LOB mid-price forecasting.

## Download Instructions
1. Go to the [official FI-2010 page](https://etsin.fairdata.fi/dataset/73eb48d7-4dbc-4a10-a52a-da745b47a649)
2. Download the `NoAuction_Zscore` training and testing files
3. Place them in this directory under:
   - `data/NoAuction_Zscore_Training/`
   - `data/NoAuction_Zscore_Testing/`

The dataset is not included in this repository due to licensing restrictions.
